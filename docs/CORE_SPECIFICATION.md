# Core Specification

Version: 0.1

## Vision
TessitoreGM is a simulation engine for persistent worlds. Narrative emerges from simulation rather than driving it.

## Fundamental Principles

1. Simulation precedes narration.
2. The world evolves independently of the player.
3. NPCs are autonomous agents.
4. Every change has a cause.
5. Knowledge is local and limited.
6. Memory is persistent.
7. Adaptability allows beliefs and behaviour to evolve without rewriting significant lived facts.
8. Prefer coherent, simple systems over unnecessary complexity.
